1.What are the 4 main built-in data structures in Python?
The four main built-in data structures in Python are: lists, tuples, sets, and dictionaries.
<br>

2.What does it mean for data to be mutable? Immutable?
Mutable means the value can be changed after creation, while immutable mean the value cannot be changed.
<br>

3.What is the difference between a list and a tuple?
Both are a ordered collection but a list is mutable and a tuple is immutable.
<br>

4.Pick one of the mutable data structures. How do you add an item to that data structure?
To add an item to the end of the list, use append().
<br>

5.How do you access an item in a list or tuple?
You access items in a list/tuple by their index.
<br>

6.What characters are used to create a list, tuple, dictionary &, set respectively?
- List: Square brackets `[]`
- Tuple: Parentheses `()`
- Dictionary: Curly braces `{}` 
- Set: Curly braces `{}` (but only values)
